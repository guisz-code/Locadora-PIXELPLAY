# 🎮 PIXELPLAY

Sistema de gerenciamento para uma locadora de **jogos e filmes**, desenvolvido em **C#** como trabalho acadêmico durante o primeiro semestre da faculdade (2025.2).

O projeto simula o funcionamento de uma locadora, permitindo cadastrar e gerenciar clientes, jogos e filmes, além de realizar e controlar aluguéis.

## ⚙️ Funcionalidades

* Cadastro de clientes
* Cadastro de jogos
* Cadastro de filmes
* Consulta de registros
* Alteração de registros
* Exclusão de registros
* Gerenciamento de aluguéis
* Controle de clientes e itens alugados
* Operações completas de CRUD

## 🛠️ Tecnologias

* C#
* .NET
* Programação Orientada a Objetos
* CRUD

## 🎓 Contexto

Projeto desenvolvido como atividade acadêmica durante o **1º semestre da faculdade — 2025.2**, com o objetivo de aplicar na prática os conhecimentos aprendidos durante a disciplina de programação.

O projeto foi proposto pelo professor e desenvolvido como uma aplicação de gerenciamento de uma locadora fictícia chamada **PIXELPLAY**.

## 📚 Objetivo

Praticar conceitos fundamentais de programação, incluindo:

* Classes e objetos
* Métodos
* Encapsulamento
* Listas e coleções
* Estruturas de decisão e repetição
* CRUD
* Organização e estruturação de um sistema em C#
